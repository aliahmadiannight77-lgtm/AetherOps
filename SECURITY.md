# Security policy

Please report suspected vulnerabilities privately through GitHub's private vulnerability reporting feature for this repository. Do not open public issues containing exploit instructions, access tokens, OTP codes, personal data, or chat content.

The project is an early-stage free-tier MVP. The current boundaries and remaining risks are documented in [`security/README.md`](security/README.md). Avoid using real sensitive data until deployment setup, access restrictions, backups, and monitoring have been reviewed.
